# Security Research

[![License: CC BY 4.0](https://img.shields.io/badge/License-CC%20BY%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/)

Independent vulnerability & malware research — technical write-ups and behavior-based detection rules (Sigma/YARA), built and tested in isolated lab environments.

## About

This repo documents how a vulnerability or piece of malware works, what it looks like in telemetry, and how to detect it — not how to weaponize it. Each write-up follows a consistent structure: overview, attack flow, telemetry analysis, detection logic, and MITRE ATT&CK mapping.

All testing is performed in isolated, non-networked lab VMs. No live payloads or exploit code are hosted here; reports link out to the original disclosure/PoC where relevant.
